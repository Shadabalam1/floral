# 🌸 Floral - Modern React Website

A modern and smooth web experience built using React, Vite, Tailwind CSS, and GSAP animations. This project focuses on performance, clean UI, and smooth scrolling effects.

---

## 🚀 Features

* ⚡ Fast development with Vite
* 🎨 Styled using Tailwind CSS
* 🎬 Smooth animations using GSAP
* 🖱️ Smooth scrolling with Locomotive Scroll
* 📱 Responsive design
* 🧩 Clean and modular React components

---

## 🛠️ Tech Stack

* React
* Vite
* Tailwind CSS
* GSAP
* Locomotive Scroll
* ESLint

---

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Shadabalam1/floral.git
```

### 2. Navigate to project folder

```bash
cd floral
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run development server

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```

---

## 👀 Preview Build

```bash
npm run preview
```
